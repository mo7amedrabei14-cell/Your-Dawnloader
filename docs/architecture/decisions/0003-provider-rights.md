# ADR 0003: Provider adapters and rights boundaries

- Status: Accepted
- Date: 2026-10-24

Adapters declare official API, supported metadata, actual representations, download authorization model, authentication, rate limits, and terms.

- Prefer official APIs, public-domain/Creative Commons sources, and content explicitly authorized for download.
- Distinguish metadata discovery, playback access, and download rights.
- Do not bypass DRM, paywalls, access controls, or provider restrictions.
- If downloads are available only through an official app, explain that and link to the official flow.
- A search result never proves that a download is legal or technically possible.
- Quality options must reflect real representations or clearly labelled local conversion outputs.
