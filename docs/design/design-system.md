# Design system direction

Premium, modern, tactile, calm, and trustworthy. React Bits is inspiration, not a blanket license to copy all components. Verify component source and license before reuse, especially for a commercial product.

- Dark/light/system themes; restrained ember-red accent.
- Glass and layered surfaces only where they preserve readability and performance.
- Clear typography, compact queue rows, obvious progress/error states.
- Keyboard-first and responsive; screen-reader semantics and visible focus.
- Arabic/English with real RTL/LTR, not only right-aligned text.
- Reduced motion always respected.
- GSAP for deliberate web marketing motion and selected transitions.
- Lenis only where useful on marketing pages; never disrupt keyboard or reduced-motion behavior.
- Avoid heavy blur/particles on download queues if they compromise legibility or performance.
