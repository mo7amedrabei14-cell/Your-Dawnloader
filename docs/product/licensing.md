# Licensing and third-party notices

The product owner's distribution license has not been selected. Source files must not be labelled as MIT or otherwise offered under an open-source license until this decision is explicit. The current Rust package metadata uses UNLICENSED to avoid implying permission to redistribute.

Before releasing binaries:
- choose a product license and add the correct LICENSE/NOTICE files;
- inventory direct and transitive dependency licenses;
- verify commercial-use rights for UI assets, fonts, media artwork, icons, and provider SDKs;
- review FFmpeg and codec build options if local conversion is shipped;
- do not copy React Bits source without checking the exact component license and the repository's MIT + Commons Clause terms;
- generate and publish a third-party software bill of materials for release artifacts.
