# Website discovery, SEO, and AI search

## Objective
Earn visibility with a useful, fast, crawlable knowledge base. First place in Google or AI search cannot be guaranteed.

## Technical requirements
- Server-rendered/indexable pages for overview, OS/browser downloads, release notes, docs, troubleshooting, privacy, security, source compatibility, and guides.
- Unique titles/descriptions, canonicals, internal links, localized Arabic/English pages and language metadata.
- Sitemap and robots routes; public pages return valid status and useful indexable content.
- Accurate structured data (SoftwareApplication where eligible); never invent ratings, prices, compatibility, reviews, or releases.
- Measure performance/accessibility, use responsive assets, and avoid client-only critical content.
- Configure the real production domain and Search Console after ownership is established.
- Version docs and changelogs to keep public facts accurate.

## AI search
Publish original technical docs, real supported-source matrices, limitations, troubleshooting, artifact integrity, and security practices. Keep facts consistent across README/site/releases. Avoid doorway pages, keyword farms, fake reviews, and unsupported comparisons.

## Metrics
Measure indexed pages, qualified organic visits, successful downloads, docs completion, and support deflection. Sitemap/schema may help machines understand pages but cannot guarantee ranking.
